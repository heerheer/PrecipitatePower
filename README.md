# Precipitate Power

NeoForge mod for sock-based materials, precipitation generators, and related integrations.

## Installation information

This template repository can be directly cloned to get started with a new mod. Open the project in IntelliJ IDEA or Eclipse after cloning.

If dependencies are missing, run `gradlew --refresh-dependencies`; use `gradlew clean` to reset generated build outputs.

For NeoForge documentation, see <https://docs.neoforged.net/>.
